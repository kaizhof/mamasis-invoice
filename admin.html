❓ چطور Token بسازم؟ (۳ دقیقه)
  1. وارد github.com شوید.
  2. روی عکس پروفایل بالا-راست کلیک کنید → Settings.
  3. در منوی چپ، پایین‌ترین گزینه: Developer settings.
  4. Personal access tokens → Tokens (classic).
  5. Generate new token → Generate new token (classic).
  6. در Note بنویسید: mamasis-admin
  7. در Expiration مقدار 90 days یا No expiration انتخاب کنید.
  8. در Select scopes فقط تیک repo را بزنید (بقیه را نزنید).
  9. Generate token را بزنید.
  10. رشته طولانی ghp_... که نمایش داده می‌شود را همین لحظه کپی کنید (بعداً دیگر نشان داده نمی‌شود).
⚠️ Token را در اختیار کسی قرار ندهید. اگر لو رفت، از GitHub آن را Revoke کنید و Token جدید بسازید.

🧺 موجودی محصولات آماده

در حال بارگذاری... kaizhof/mamasis-invoice
سوییچ هر محصول را خاموش/روشن کنید. تغییرات با دکمه «ذخیره» اعمال می‌شود.
📖 راهنمای استفاده روزمره
  1. هر محصولی که موجود است، سوییچش را روشن (سبز) بگذارید.
  2. هر محصولی که ناموجود است، سوییچش را خاموش (خاکستری) کنید.
  3. دکمه «💾 ذخیره در مخزن» را بزنید.
  4. صفحه کاربر (index.html) به صورت خودکار هر ۶۰ ثانیه موجودی جدید را می‌خواند. کاربران می‌توانند با دکمه «🔄 به‌روزرسانی» فوری چک کنند.
💡 محصولات ناموجود در صفحه کاربر با برچسب قرمز «ناموجود» نمایش داده می‌شوند و کاربر می‌تواند با دکمه «🔔 درخواست موجود شدن» آن را رزرو کند.
🔔 چطور رزروها را ببینم؟

رزروها در localStorage دستگاه کاربر ذخیره می‌شوند (نه در سرور). برای دیدن آن‌ها:

  1. کاربر فاکتور نهایی را از پایین صفحه کپی می‌کند و برای شما می‌فرستد.
  2. در فاکتور، بخشی با عنوان «🔔 رزروهای در انتظار موجودی» وجود دارد.
  3. بر اساس آن، محصولات رزروشده را موجود کنید.
💡 اگر تعداد رزروها زیاد شد، می‌توانیم در آینده یک سرور کوچک (Vercel) اضافه کنیم تا رزروها در پنل ادمین نمایش داده شوند.
⚠️ عیب‌یابی
  • «ذخیره شد» ولی در صفحه کاربر تغییر نکرد: کش مرورگر. صفحه کاربر را با Ctrl+Shift+R رفرش کنید یا دکمه «🔄 به‌روزرسانی» را بزنید.
  • خطای 401: Token اشتباه است یا منقضی شده. Token جدید بسازید.
  • خطای 404: نام مخزن یا شاخه اشتباه است. بررسی کنید kaizhof/mamasis-invoice و main درست باشند.
  • خطای 403: Token دسترسی repo ندارد. Token جدید با دسترسی درست بسازید.
🔒 امنیت Token
  • Token فقط در localStorage همین مرورگر ذخیره می‌شود.
  • هیچ‌وقت آن را در کد هاردکد نکنید یا در مخزن عمومی نگذارید.
  • اگر دستگاه را به کسی می‌دهید، اول «🚪 خروج» را بزنید.
  • اگر Token لو رفت، از GitHub آن را Revoke کنید و Token جدید بسازید.
