📚 راهنمای استفاده

👤 راهنمای کاربر
  1. انتخاب محصول: با دکمه + تعداد را زیاد کنید. محصولات موجود با رنگ گرم مشخص‌اند.
  2. محصول ناموجود: با برچسب قرمز «ناموجود» مشخص می‌شود. با دکمه 🔔 درخواست موجود شدن می‌توانید آن را رزرو کنید تا در فاکتور به عنوان زنبیل ثبت شود.
  3. خرید با بودجه: بودجه‌تان را وارد کنید تا سبد خودکار چیده شود.
  4. تست مزاج: به ۴ سوال پاسخ دهید تا پیشنهادهای اختصاصی بگیرید.
  5. زنبیل: هر محصول زنبیل باید به ۲.۵ کیلو برسد تا تولید شروع شود. پیشرفت در همان کارت نمایش داده می‌شود.
  6. فاکتور نهایی: در پایین صفحه، فاکتور را کپی کنید و برای ادمین بفرستید.
💡 اگر موجودی به‌روز نیست، دکمه 🔄 به‌روزرسانی بالای صفحه را بزنید.
🔧 راهنمای ادمین

ورود به پنل ادمین: آدرس /admin.html را باز کنید. یک بار GitHub Token را وارد کنید (در همان دستگاه ذخیره می‌شود).

ساخت Token:

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token → فقط تیک repo
  3. Token را کپی و در پنل ادمین بچسبانید.

مدیریت موجودی: سوییچ هر محصول را خاموش/روشن کنید و «💾 ذخیره در مخزن» را بزنید. تغییرات حدود ۱ دقیقه بعد در صفحه کاربر اعمال می‌شود (یا با دکمه به‌روزرسانی فوری).

درخواست‌های رزرو: در فاکتورهایی که کاربران برایتان می‌فرستند، محصولات با برچسب 🔔 در انتظار موجودی مشخص‌اند. آن‌ها را موجود کنید تا سفارش تکمیل شود.

⚠️ Token را در اختیار کسی قرار ندهید. در صورت لو رفتن، از GitHub آن را Revoke کنید.
❓ سوالات متداول

چرا محصولی ناموجود شده؟ ادمین موجودی را به‌روزرسانی کرده است. می‌توانید درخواست موجود شدن بدهید.

زنبیل چیست؟ محصولاتی که فقط با رسیدن به ۲.۵ کیلو تولید می‌شوند. با افزایش تعداد، پیشرفت را ببینید.

آیا رزرو تضمینی است؟ رزرو در فاکتور ثبت می‌شود و ادمین بر اساس آن موجودی را تأمین می‌کند. پرداخت پس از تأیید موجودی انجام می‌شود.
